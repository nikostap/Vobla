# M2 — Identity и профиль

## Что проверить

1. Открыть `/Account/SignIn`, ввести любой корректный email и получить код от fake-provider.
2. Ввести показанный шестизначный код: новый email должен создать аккаунт, существующий — открыть сессию.
3. На `/Account/Profile` изменить имя, город, описание и настройки приватности; обновить страницу и убедиться, что изменения сохранены.
4. На `/Account/Sessions` увидеть текущую сессию. Вторая сессия того же пользователя может быть завершена кнопкой «Завершить».
5. На `/Account/RoleDemo` увидеть назначенную роль и журнал действий. Email `admin@marketplace.local` получает роль администратора.

## Автоматическая приёмка

- `dotnet build Marketplace.slnx --configuration Release` без предупреждений и ошибок;
- `npm test` в `tests/UiTests`;
- `docker compose up --build -d`, затем `GET /health` возвращает `200 Healthy`;
- PostgreSQL healthy и миграция `InitialIdentity` применена при старте приложения.

## Известные ограничения

- fake-provider показывает код только для локальной демонстрации; реальная доставка email/SMS не подключена;
- второй фактор для административных ролей запланирован для production-контура;
- профиль хранит основу публичных данных и приватности, но аватар и верификация личности будут расширены следующим контуром Identity.
