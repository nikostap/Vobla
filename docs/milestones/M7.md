# M7 — География и карта

## Что проверить

1. На главной по умолчанию выбрана Москва, радиус — 30 км; источник fallback явно указан в диалоге.
2. Нажать город: вручную доступны Москва, Санкт-Петербург, Казань, Екатеринбург, Новосибирск и вся Россия.
3. Отказать browser geolocation: появляется понятное сообщение, ручной выбор продолжает работать.
4. Переключить list/split/map: режим сохраняется cookie и восстанавливается при следующем открытии.
5. На дальнем zoom объявления объединяются; на близком zoom распадаются до отдельных preview с фото и ценой.

## Автоматическая приёмка

- `ListingLocation` отделяет точные координаты/адрес от публичной стабильной точки; публичная выдача читает только public point;
- `IIpGeoAdapter` и `IMapProviderAdapter` изолируют GeoIP и будущий production Яндекс Maps SDK;
- радиус считается по Haversine от публичных координат;
- миграция `ListingGeography` применена;
- Release build без ошибок/предупреждений, 22/22 Playwright UI-тестов, visual regression и health прошли.

## Ограничения

- `DemoYandexMapAdapter` реализует контракт, кластеризацию и UI без внешнего API-ключа; production adapter подключит официальный SDK;
- локальный IP adapter намеренно возвращает безопасный fallback Москва;
- точный адрес пока не вводится в мастер, но схема хранения и запрет публичной выдачи уже действуют.
