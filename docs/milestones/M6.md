# M6 — Поиск и фильтры

## Что проверить

1. Ввести запрос на главной странице: форма работает обычным GET без JavaScript, параметры остаются в URL.
2. Одобрить объявление в модерации и найти его по части названия или опечатке: источник выдачи помечен как «база данных».
3. Открыть «Фильтры», выбрать цену, состояние, тип сделки, фото и категорию; после выбора категории появляются поля опубликованной динамической схемы.
4. Обновить страницу: запрос, фильтры и сортировка восстановлены; сортировка дополнительно сохраняется в cookie.
5. Ввести заведомо отсутствующий запрос: отображается полезный empty state со сбросом.

## Автоматическая приёмка

- PostgreSQL full-text для русской морфологии и `pg_trgm`/`word_similarity` для опечаток;
- миграция `SearchTrigrams` включает управляемое расширение `pg_trgm`;
- Release build без ошибок и предупреждений;
- 19/19 Playwright UI-тестов, включая DB listing → approval → typo search → refresh → empty state;
- visual regression, Docker, PostgreSQL и health endpoint прошли.

## Ограничения

- без критериев сохраняется стабильная demo-выдача из JSON; активные объявления из PostgreSQL участвуют в реальном поиске и фильтрах;
- текущая выдача ограничена 100 результатами, пагинация будет добавлена при росте данных;
- поисковые подсказки, синонимы и история запросов остаются следующим расширением поиска.
