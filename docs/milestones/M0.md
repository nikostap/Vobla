# M0 — Bootstrap и живой UI-shell

## Что проверять

1. Запустить `docker compose up --build` и открыть <http://localhost:5080>.
2. Убедиться, что видны шапка, поиск, город, категории, фильтры, восемь карточек и fake-map.
3. Навести указатель на карточку: связанный marker карты должен увеличиться; обратное взаимодействие работает так же.
4. Нажать сердце на фото: оно переключается без перехода со страницы.
5. На ширине меньше 1200 px нажать плавающую кнопку «Карта», затем «Список».
6. Проверить отсутствие горизонтального overflow на 390, 768, 1366 и 1920 px.
7. Открыть <http://localhost:5080/health>: ожидается `Healthy`.

## Seed-данные

Восемь демонстрационных объявлений загружаются сервером из `src/Marketplace.Web/Data/sample-listings.json`. Изображения локальные, внешняя сеть сайту не нужна.

## Известные ограничения

- карта является визуальным fake-компонентом и не использует API карт;
- элементы фильтрации и пользовательское меню демонстрируют UI-состояния, но не бизнес-операции;
- данные только для чтения и перезагружаются из JSON после рестарта;
- тёмная тема и component gallery относятся к M1;
- публичный Staging URL не настроен, используется локальный URL.
