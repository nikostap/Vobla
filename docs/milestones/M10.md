# M10 — Рекомендации и сохранённые поиски

## Что проверить

1. Авторизованный пользователь задаёт поисковый запрос или фильтры и сохраняет их одной кнопкой; повторно тот же набор не дублируется.
2. `/Recommendations` показывает сохранённые поиски, актуальное количество результатов и прирост после предыдущей проверки.
3. Для каждого сохранённого поиска можно выключить уведомления или удалить его.
4. Просмотры объявлений и поиски хранятся 30 дней, доступны пользователю и удаляются кнопкой «Очистить историю».
5. Настройка «Персональные рекомендации» в профиле полностью прекращает запись и показ личной истории, не отключая сохранённые поиски.
6. На карточке объявления отображаются похожие активные объявления с учётом категории, города, состояния, близости цены, наличия фото и свежести.

## Автоматическая приёмка

- миграция `RecommendationsAndSavedSearches` применена;
- уникальные ограничения не допускают дубли просмотра, истории запроса и сохранённого поиска;
- Release build: 0 ошибок, 0 предупреждений;
- 25/25 Playwright UI-тестов, включая M10 end-to-end;
- `GET /health` возвращает `200 Healthy`, оба Docker-контейнера работают.

## Ограничения

- проверка новых совпадений выполняется при открытии `/Recommendations`; фоновый планировщик относится к M11;
- первая версия рекомендаций rule-based, без ML и внешнего профилирования;
- история хранится в основной PostgreSQL БД, отдельное аналитическое хранилище пока не используется.
