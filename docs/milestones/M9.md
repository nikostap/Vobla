# M9 — Избранное, сравнение, сделки и отзывы

## Что проверить

1. Авторизованный пользователь одним действием добавляет/удаляет объявление из избранного и сравнения.
2. В сравнении допустима одна категория; таблица показывает цену, продавца, состояние, dynamic attributes и режим «только различия».
3. Покупатель в чате нажимает «Я купил товар», продавец подтверждает; объявление получает `Completed`.
4. До подтверждения форма отзыва отсутствует; после — каждая сторона может оставить один отзыв 1–5 с отметкой подтверждённой сделки.
5. При снижении цены пользователь из избранного получает уведомление, а новая цена сохраняется как база следующего снижения.

## Автоматическая приёмка

- миграция `EngagementDealsReviews` применена;
- уникальные ограничения не допускают дубли favorite/compare/deal/review;
- rating защищён DB check constraint 1–5;
- Release build 0 ошибок/предупреждений;
- 24/24 Playwright UI-тестов, полный M9 end-to-end прошёл.

## Ограничения

- сравнение базовой версии требует точного совпадения категории;
- публичная страница рейтинга и агрегация по ролям остаются расширением;
- безопасная оплата не реализована: Deal подтверждается сторонами без хранения денег платформой.
