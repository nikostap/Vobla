# M4 — Создание и управление объявлениями

## Что проверить

1. Войти и открыть `/Listings/Create`: заполнить три шага, сохранить черновик и отправить объявление на проверку.
2. Открыть `/Listings/My`: объявление отображается со статусом «На проверке».
3. Открыть карточку объявления: видны галерея, характеристики, история цены, ревизии и статусы.
4. Изменить цену и название: появляются новая цена и новая ревизия.
5. Изменить категорию: создаётся новое объявление, исходное архивируется.

## Автоматическая приёмка

- Release build без ошибок и предупреждений;
- 17 Playwright UI-тестов;
- сквозной тест M4 покрывает создание, динамические атрибуты, preview, публикацию, историю цены, ревизии и смену категории;
- Docker и PostgreSQL healthy.

## Ограничения

- локальное файловое хранилище используется для demo-загрузок; production потребует object storage, antivirus и image pipeline;
- autosave выполняется при переходе между шагами; фоновое сохранение во время ввода будет добавлено позже;
- автоматическая проверка реализуется в M5.
