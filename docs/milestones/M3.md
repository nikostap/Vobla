# M3 — Каталог и seed-структура

## Что проверить

1. Открыть `/Catalog`: доступны исходные верхнеуровневые разделы и вложенная навигация.
2. Открыть `prodazha-kvartir`, `sedany`, `igrovye-noutbuki`, `divany`: отображается форма атрибутов из опубликованной схемы.
3. Войти как `admin@marketplace.local`, открыть `/Admin/Catalog`, добавить вложенную категорию и увидеть её на `/Catalog` без пересборки.
4. Создать новую версию схемы для «Игровых ноутбуков»: версия увеличивается, атрибуты копируются.

## Автоматическая приёмка

- Release build без ошибок и предупреждений;
- 16 Playwright UI-тестов;
- PostgreSQL содержит таблицы каталога;
- Docker health endpoint отвечает `200 Healthy`.

## Ограничения

- Детальное редактирование состава атрибутов будет расширено вместе с мастером объявлений M4.
